MHMMotivational Health Messages

First run

Get started.

Tell MHM your name, choose what to turn on, then set up each of those. You can change any of this later in Account.

    What should MHM call you?

    A preferred name and time zone are enough to start.

    Connect Discord?

    Connect Discord if you want MHM there. You can also do this later in Account.

    If you do not connect Discord, MHM uses email. Reminders and check-ins can still arrive by email, and you can reply to those messages. You can also answer a check-in on this website. Thumbs reactions that change later messages are only in Discord.

    How should MHM show up?

    Pick at least one. Each feature you leave on gets its own short setup next.

    Which messages should MHM send?

    Pick at least one category. A quiet evening window is ready for each one you choose.

    Categories personalized from check-ins or Google Health can be turned on in Account after this setup.

    When should those messages arrive?

    Change a window, add another, or keep the ones already filled in.

    One first task.

    Something small counts. You can skip this and add it later.

    When should task reminders arrive?

    An afternoon window is ready. Change it, add another, or keep it.

    Which check-in questions should MHM ask?

    Always questions are included every time. Sometimes questions rotate, and at least one of those stays out.

    Custom questions can be added in Account after this setup.

    When should check-ins arrive?

    A morning window is ready. Change it, add another, or keep it.
